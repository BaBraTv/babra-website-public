## Final Pre-Deployment Steps

1. Push `codex/production-readiness` to GitHub if not already pushed.
2. Open a pull request into `main`.
3. Review the Vercel preview visually on desktop, tablet, and mobile.
4. Run Lighthouse on the preview URL.
5. Confirm Supabase production environment variables are present in Vercel.
6. Confirm email/payment provider placeholders are acceptable for launch scope.
7. Confirm official media and content approvals with BaBra leadership.
8. Merge only after approval.
9. Let Vercel deploy from `main`.
10. Verify `https://www.babra.store` after production deployment.
